# Roblox RP Внешний Чат-Оверлей

Полностью функциональное, готовое к запуску десктопное приложение и сервер реального времени, созданные специально для комфортных ролевых сессий (RP) в играх Roblox (Brookhaven, Emergency Hamburg, Bloxburg, South London 2, Liberty County, SRP и др.).

---

## 🌟 Ключевые возможности

1. **Аутентичный стиль Roblox**:
   - Полупрозрачная темная подложка (`#191B1F`), в точности повторяющая оригинальный чат Roblox.
   - Четкая современная типографика с цветным выделением никнеймов, фракций/позывных и системных сообщений.
   - Возможность включать или выключать отображение временных меток сообщений `[ЧЧ:ММ:СС]`.
   - Плавная автоматическая прокрутка истории сообщений и подгрузка бэклога при входе в комнату.

2. **Поведение окна и игровой оверлей (Gaming Mode)**:
   - **Всегда поверх всех окон (Always-On-Top)**: чат отображается поверх игр в полноэкранном оконном режиме (Borderless Windowed).
   - **Быстрый фокус по клавише `/`**: нажмите `/` в любой момент игры, чтобы мгновенно активировать ввод в чат (кнопка `Esc` возвращает фокус в игру).
   - **Звуковые уведомления и кастомный звук**: звуковое оповещение о сообщениях других игроков, возможность отключить звук или указать путь к своему аудиофайлу (.wav / .mp3). Свои сообщения не озвучиваются!
   - **Блокировка позиции (`Ctrl+L`)**: зафиксируйте окно горячей клавишей или кнопкой 🔓/🔒, чтобы избежать случайного смещения.
   - **Глобальная клавиша (`F3`)**: моментально скрыть или вернуть чат на экран в любой момент игры.

3. **Команды ролевой игры (RP Engine)**:
   - `/me <действие>`: Физическое действие персонажа от 1-го лица курсивом (`* Officer_John достает служебный тайзер *`).
   - `/do <окружение>`: Описание обстановки или последствий от 3-го лица (`* Багажник автомобиля опечатан (( Officer_John )) *`).
   - `/try <действие>`: Честная серверная проверка удачи 50/50: возвращает `[Удачно]` или `[Неудачно]` (`* Officer_John Взломал навесной замок [Удачно] *`).
   - `/b <текст>` или `// <текст>`: Внеигровое общение (OOC) без нарушения RP-атмосферы (`(( [OOC] Officer_John: Отойду на 2 минуты ))`).
   - `/s <текст>`: Громкий крик с выделением ярким янтарным цветом.
   - `/c <текст>`: Тихий голос / шёпот (`[Тихо] Officer_John: Тихо, охрана близко...`).
   - `/clear`: Быстрая очистка экрана чата у себя.
   - `/help`: Встроенная справка по всем командам.

4. **Система приватных комнат и кастомизация**:
   - Вход по коду комнаты (например: `LSPD-PATROL`, `BLOX-RP-1`), благодаря чему сообщения видят только участники вашей сессии.
   - **Никнеймы на английском языке** (например: `Officer_John`, `Blox_R`, `Deputy_Mark`).
   - **Выбор цвета ника по RGB**: встроенная палитра `QColorDialog` позволяет выбрать абсолютно любой HEX/RGB цвет для своего имени.
   - Автоматическое сохранение параметров в файл `overlay_config.json`.

## 🌐 Инструкция по подключению через Radmin VPN

Radmin VPN — это бесплатная и быстрая виртуальная локальная сеть, которая позволяет играть с друзьями без белого IP и без настройки проброса портов на роутере.

### Шаг 1: Подготовка хоста (Тот, у кого запущен сервер)
1. Скачайте и установите **Radmin VPN** с официального сайта: [radmin-vpn.com](https://www.radmin-vpn.com/).
2. В окне Radmin VPN нажмите большую кнопку **«Включить»**.
3. Нажмите в верхнем меню: **Сеть** ➔ **Создать новую сеть**.
4. Введите имя сети (например: `Roblox-RP-Squad`) и придумайте пароль (например: `rp12345`). Нажмите *«Создать»*.
5. В верхней строке Radmin VPN найдите ваш **виртуальный IP-адрес** (он начинается с `26.x.x.x`, например: `26.154.32.10`). Кликните по нему правой кнопкой мыши и выберите *«Копировать IP-адрес»*.
6. Запустите сервер в терминале:
   ```bash
   python server.py
   ```
   *(Если брандмауэр Windows спросит разрешение, отметьте галочками «Частные сети» и нажмите «Разрешить доступ»).*

### Шаг 2: Подключение игроков (Друзья)
1. Друзья также устанавливают и включают **Radmin VPN**.
2. В Radmin VPN нажимают: **Сеть** ➔ **Подключиться к существующей сети**.
3. Вводят имя сети (например: `Roblox-RP-Squad`) и пароль, который дал хост.
4. Запускают клиент оверлея:
   ```bash
   python client.py
   ```
5. В открывшемся окне чата нажимают иконку **Шестеренки (⚙)**:
   - В поле **Адрес сервера** вставляют IP хоста с портом:
     `http://26.154.32.10:5000` *(замените `26.154.32.10` на реальный IP хоста из Radmin VPN!)*.
   - В поле **Имя персонажа** указывают никнейм на английском (например: `Officer_Cole`).
   - В поле **Код комнаты** указывают общий канал (например: `BROOKHAVEN-LSPD`).
   - Нажимают **«🎨 Выбрать RGB»**, чтобы задать уникальный цвет ника.
   - Нажимают **«Сохранить и Применить»**.
6. Индикатор в верхнем левом углу загорится **зеленым (●)** — вы в общей RP-комнате!

## 🚀 Локальный запуск (На одном ПК)

```bash
# 1. Установка библиотек
pip install -r requirements.txt

# 2. Запуск сервера (Терминал 1)
python server.py

# 3. Запуск десктопного оверлея (Терминал 2)
python client.py
```

## ⌨️ Таблица горячих клавиш

| Клавиша | Назначение |
|---|---|
| `/` | Мгновенно активировать ввод в чат с префиксом `/` |
| `Enter` | Отправить сообщение или активировать поле ввода |
| `Стрелки Вверх / Вниз` | Навигация по истории ранее отправленных команд |
| `Ctrl + L` | Заблокировать / разблокировать перемещение оверлея |
| `F3` (или `Ctrl+Shift+C`) | Глобально скрыть или показать оверлей поверх игры |
| `—` (В шапке) | Свернуть оверлей в компактную полоску |
